Reach the backend model over its OpenAI-compatible API, authenticated with a per-user key you mint on the API Keys page.

Enable Tailscale for long requests

Install Tailscale, sign in with the identity invited by the administrator, and keep it enabled while using Zoo Code or Hermes. The Base URL above does not change: connected users reach it privately and bypass Cloudflare's first-byte timeout.

  • Windows, macOS, iOS, and Android accept the private route automatically.
  • On Linux, run sudo tailscale set --accept-routes=true.
  • Leave Use Tailscale DNS settings enabled.
  • If Tailscale is off, the same URL falls back to Cloudflare. Short requests can still work, but a queued request may return HTTP 524.
  • If Tailscale is on but private DNS is unavailable, disable Tailscale to deliberately use the Cloudflare fallback.

Quick check: curl -sS -D - -o /dev/null {{ llm_base_url | replace('/v1', '') }}/health/liveliness. The private path has no cf-ray response header.

Direct API integration

Point any OpenAI-compatible client or editor extension at the endpoint above. First mint a key on the API Keys page (it's shown once), then drop it into the config below in place of <YOUR_KEY>.

Recommended client limits

The server has a 262,144-token hard limit covering the prompt and response. Advertise 245,760 tokens to clients and reserve 8,192 output tokens; the remaining margin covers tokenizer differences, tool schemas, and chat-template overhead.

Zoo Code 3.76+

Open Settings → OpenAI Compatible. Under Custom Model Capabilities, set:

  • Context Window Size: 245760
  • Max Output Tokens: 8192
  • Include max output tokens: enabled

Hermes Desktop

Set Settings → Custom Endpoints → Context and Settings → Model → Context Window to 245760. The equivalent Hermes configuration is: 

model:
  context_length: 245760
  max_tokens: 8192
compression:
  enabled: true
  threshold: 0.5

Image requests accept at most two images and automatically downsize each to 4 MP. Crop very tall full-page screenshots into focused sections so small text remains legible and responses stay below the proxy timeout.

VS Code — Cline (agentic)

Prefer agentic, multi-file editing? In Cline's settings choose API Provider OpenAI Compatible, set Base URL to {{ llm_base_url }}, API Key to your seko key, and Model ID to {{ llm_model }}. Cline leans on the model's tool-calling, so expect heavier token use than plain chat.

Image generation and editing

Generate, edit, and inpaint images through the hosted interfaces or the OpenAI Images-compatible API. Your same seko key covers every model currently offered by the gateway; there is no separate image entitlement.

Model Capabilities Typical latency Choose it for
{{ image_model }} Fast generation, editing, inpainting 4-8 seconds to generate; edits are usually about 12-13 seconds Default interactive work, drafts, and changing one source image
{{ image_quality_model }} Generation only Usually 4-5 minutes Typography, fine detail, and difficult prompt adherence

API contract at a glance

Base URL
{{ llm_base_url }}
Generate
POST /images/generations
Edit / inpaint
POST /images/edits with {{ image_model }}
Sizes
1024x1024, 1536x1024, or 1024x1536
Output
One image (n must be 1) as b64_json

Generation, editing, and inpainting share one queue: one request runs and one waits. A third concurrent request receives 429; retry it after either slot finishes.

Generated server files are removed after the response; the API is not a persistent gallery.

Keep Tailscale connected for {{ image_quality_model }}. Its multi-minute response can exceed Cloudflare's off-tailnet first-byte timeout. Normal FLUX work is designed for interactive use.

Hosted Open WebUI (recommended for people)

Sign in with SSO and open chat.pushprh.com/playground/images. Generated and edited media is owned by your authenticated account and kept separate from other users.

For inline generation in a normal {{ llm_model }} conversation, open the composer’s Integrations → Image toggle. Image-only models are intentionally absent from the chat model picker; do not select {{ image_model }} as a chat model.

Generate with curl

curl {{ llm_base_url }}/images/generations \
  -H "Authorization: Bearer <YOUR_KEY>" \
  -H "Content-Type: application/json" \
  -d '{"model":"{{ image_model }}","prompt":"A cozy cabin under the northern lights","n":1,"size":"1024x1024","response_format":"b64_json"}' \
  | jq -r '.data[0].b64_json' | base64 --decode > image.png

Edit or inpaint one image

curl {{ llm_base_url }}/images/edits \
  -H "Authorization: Bearer <YOUR_KEY>" \
  -F model={{ image_model }} \
  -F prompt="Change the jacket to blue" \
  -F size=1024x1024 \
  -F image=@source.png \
  -F mask=@mask.png \
  | jq -r '.data[0].b64_json' | base64 --decode > edited.png

Omit mask for a prompt-guided edit of the whole image. For inpainting, use a same-size RGBA PNG mask with transparency. Transparent pixels are editable; opaque pixels are preserved.

The source can be PNG, JPEG, or WebP. Each upload is limited to 20 MiB, 20 million pixels total, and 8192 pixels per dimension. The API accepts one source image and an optional mask; it rejects multiple sources, URLs, server paths, arbitrary workflows, custom nodes, and Qwen edits.

OpenAI SDK (Python)

import base64
from openai import OpenAI

client = OpenAI(base_url="{{ llm_base_url }}", api_key="<YOUR_KEY>")
result = client.images.generate(
    model="{{ image_model }}",
    prompt="A cozy cabin under the northern lights",
    size="1024x1024",
    response_format="b64_json",
)
with open("image.png", "wb") as image:
    image.write(base64.b64decode(result.data[0].b64_json))

Hermes Discord and Desktop

Ask Hermes to create an image in plain language. To edit, attach exactly one source image and describe the change; Hermes routes it to FLUX and returns a native image attachment. Hermes does not expose masks or multiple reference images. Use Open WebUI or the direct API when you need inpainting controls.

MCP agents

Add a Streamable HTTP server at https://llm.pushprh.com/mcp/ and send your seko key as Authorization: Bearer <YOUR_KEY>. The trailing slash is required; some clients do not preserve the POST body through the redirect from /mcp.

  • image-image_generate generates with FLUX or Qwen.
  • image-image_edit edits with FLUX and optionally accepts a mask.

Source and mask inputs are inline base64, not URLs or server paths. Results include standard MCP image content, so the client must support image content and request sizes large enough for base64 input and output.

Codebase indexing (Zoo Code)

The homelab serves a local embeddings model so editor extensions can do semantic “find the code that does X” retrieval over your whole repo. Your seko key already works for embeddings — no separate key needed. The vector database that stores the index runs on your own machine.

{{ embedding_model }}
Dimension
{{ embedding_dimension }}

Step 1 — run Qdrant on your own machine

Zoo Code stores the index in a Qdrant vector database. Install and start it locally by following the official Qdrant installation guide — it covers Docker, Windows, Linux and macOS.

  • The default local endpoint is http://localhost:6333.
  • No API key is needed for an instance that only listens on localhost.
  • It must be running whenever you index or search.
  • Check it’s up: curl http://localhost:6333/healthz

The index stays on your own disk — nothing about your code is stored on the homelab, and you can always delete the collection and re-index.

Step 2 — VS Code, Zoo Code (Roo/Kilo-style indexing)

In Zoo Code open Settings → Codebase Indexing and set:

  • Embedder provider: OpenAI Compatible
  • Base URL: {{ llm_base_url }}
  • API key: your seko key
  • Model: {{ embedding_model }}
  • Embedding dimension: {{ embedding_dimension }}
  • Qdrant URL: http://localhost:6333 · Qdrant API key: leave blank

Then click Start indexing.

Previously this page pointed Qdrant at a shared homelab instance. If you indexed against that, your first local index starts from scratch — just re-run Start indexing.

Verify the embeddings endpoint — curl

curl {{ llm_base_url }}/embeddings \
  -H "Authorization: ******" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{ embedding_model }}", "input": "hello"}'

A {{ embedding_dimension }}-length vector in data[0].embedding means you’re set.
